# 项目设计

## 目标

复现并审计风机 SCADA 无监督早期异常检测方法，重点比较统计、工况条件残差和深度时序自编码器在 CARE 数据集上的事件级预警表现。

## 范围

**包含**

- CARE 数据读取、状态筛选、时间连续分段与特征工程；
- PCA、Isolation Forest、条件残差、Dense AE、VAE、LSTM-AE 与 Transformer-AE；
- 正常数据训练、验证期阈值校准、prediction-only 评估；
- AUC-ROC 辅助诊断与 CARE 事件级报表。

**暂不包含**

- 故障机理的因果定位；
- 线上服务、实时部署与前端系统；
- 私有 SCADA 数据或跨场站迁移训练。

## 评估原则

1. 训练只使用正常行为数据，异常标签不进入模型训练。
2. 阈值由验证期数据得到；prediction 分区只用于最终报告。
3. CARE 是主指标；AUC-ROC 只衡量分数排序能力。
4. 每次实验写出配置、随机种子、阈值和逐事件告警结果。

## 已知限制

- CARE 事件窗常与停机或维护状态重叠；必须报告事件可评分性，不能仅用单一 AUC 概括。
- Nair & Babu 与 CARE benchmark 的数据切分、状态过滤及阈值机制并不完全相同，数值不应直接横向比较。
- CARE benchmark 论文未公开风速/功率辅助过滤的精确阈值；该假设需在实验输出中明确。
