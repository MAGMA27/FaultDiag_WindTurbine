# 项目设计文档 (Project Design Doc)

## 目标与动机

- **目标**: 复现并审计 Nair & Babu (2025) 的 Hybrid Autoencoder 框架，在 CARE 风电场 SCADA 数据上实现无监督的早期异常预警。
- **动机**: 作为求职作品集项目，展示端到端的机器学习研究能力——从论文精读、数据工程、模型实现到实验评估与结果呈现。
- **定位**: 强调「可复现」与「代码整洁」，而非追求 SOTA。

## 范围

**在范围内**
- CARE 数据集加载与清洗（按风场、按事件划分）
- 特征工程流水线：时序、统计、频域指标
- 对照：PCA + Isolation Forest、工况条件残差模型与一个强时序 AE；多模型集成作为最后的消融
- 异常打分（重构误差）→ 自适应百分位阈值（τ∈[95,99]）
- 评估：以 CARE score（Coverage、Accuracy、Reliability、Earliness）为主，配合事件级预警、误报率、24/48h 覆盖率；AUC-ROC 仅作辅助诊断

**不在范围内（后续可扩展）**
- 论文 2 的生成式域适应 / 数据稀缺迁移（另行立项）
- 模型部署、实时推理、Web 前端

## 成功标准

- 实验可一键复现（固定种子、配置化）
- 严格冻结 prediction-only 测试协议，在事件级 CARE 指标下透明比较基线与深度模型；不以复刻单个 AUC 数字作为成功条件
- 代码通过 `ruff` 校验与 `pytest` 基本测试
- `README` + `memory-bank` 能讲清方法、数据与结论

## 关键技术决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 包管理 | `uv` | 快速、可复现、锁定依赖 |
| 深度学习框架 | PyTorch（默认 CPU 版） | 论文用 AE/Transformer；CPU 版安装小，GPU 可后续开启 |
| Python 版本 | 3.13（`<3.14`） | 与当前环境一致，避免多版本解析分裂 |
| 评估协议 | 无监督（正常数据训练，异常仅用于评估） | 对齐论文设定 |
| 主指标 | CARE score + 事件级运维指标 | 对齐 CARE benchmark 的实际预警目标，抑制点级 AUC 的误导 |
